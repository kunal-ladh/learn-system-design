WHAT IS IT:
-----------
A configurable risk assessment engine used across Niyo's banking products to
evaluate customer risk profiles during onboarding. It integrates with third-party
data providers (Sign3 for social/digital footprint, CKYC for identity verification)
and applies rule-based risk scoring.

WHAT I BUILT:
-------------
a) Core Risk Engine APIs:
   - LOB (Line of Business) REST API — full CRUD
   - Attribute API for configuring risk parameters
   - Subrule CRUD APIs with ordering logic
   - Preference management APIs (create, update, approve/reject workflow)
   - Utility APIs for operational support

b) Rule Engine & Validators:
   - Built validators for: Address, CKYC, Common, CRIF, DeviceId, Email,
     Income, IpAddress, Occupation, PIN
   - Each validator had comprehensive unit tests (parameterized tests)
   - Social count gate logic (set to 80% threshold)

c) Sign3 Integration:
   - Integrated Sign3 third-party API for digital footprint data
   - Added fields for WhatsApp, Google, LinkedIn, Skype presence
   - Built user report download API (Excel format)
   - Added Sign3 data enrichment to risk profiles

d) Data Management:
   - CSV and Excel upload/download functionality for bulk operations
   - Later removed CSV in favor of Excel-only (cleaner UX)
   - Bulk override functionality for risk rules
   - Fixed duplicate preference approval issues

e) Code Quality & Testing:
   - Wrote comprehensive unit tests for all validators
   - Service layer tests (RiskServiceImpl, UploadServiceImpl, etc.)
   - Parameterized tests to reduce code smells
   - Sonar fixes across the entire codebase
   - Separated Data Access Layer (DAL) for cleaner architecture

f) Bug Fixes:
   - Fixed duplicate change-request approval bug (NIYOB-1703)
   - Fixed null rows in bulk override (NIYOB-1704)
   - Fixed NPE in User CKYC details
   - Fixed update-subrule request ordering issue
   - Fixed user details API auth issue
