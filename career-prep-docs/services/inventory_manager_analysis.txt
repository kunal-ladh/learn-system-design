4. KEY ARCHITECTURAL DECISIONS
================================================================================

4.1 Authentication Architecture
  - Built a custom Spring Security authentication system from scratch
  - Supports dual authentication: JWT-Visionary tokens AND service-to-service (S2S) API calls
  - Custom NiyoAuthenticationProvider with full JWT parsing (Claims, JwtClaims, JwtMap)
  - DownstreamContextFilter for propagating user context across microservices
  - Role-based access control with ROLE_ prefix convention

4.2 Inter-Service Communication
  - Chose Retrofit + OkHttp over RestTemplate/WebClient for external API calls
  - Built RestTemplateHeaderModifierInterceptor for header propagation
  - HeaderInjectorInterceptor for custom header injection
  - CustomerServiceApiClient for customer service integration
  - NotificationApiClients for email notification service

4.3 Event-Driven Architecture
  - Apache Kafka for asynchronous processing
  - SASL_PLAINTEXT security for UAT, PLAINTEXT for dev
  - Zstd compression for optimized message throughput
  - Kafka workers with production enable/disable toggle
  - Dynamic topic creation beans

4.4 Data Architecture
  - MongoDB as primary data store
  - Dynamic query builders for flexible filtering
  - MapStruct for type-safe object mapping between layers
  - Javers for object audit/diff tracking

4.5 File Storage & Reporting
  - AWS S3 for file storage with pre-signed URL generation
  - Apache POI for Excel report generation (SpreadSheetWriterService)
  - Reports uploaded to S3 (card kit lost reports, issuance reports)

4.6 Containerization Strategy
  - Google Jib for Docker-less container builds
  - Multi-architecture support (amd64 + arm64)
  - Base image management with regular security updates

4.7 Configuration Management
  - AWS Secrets Manager for credential storage
  - Jasypt for encrypted configuration properties
  - Environment-specific configs (dev, UAT, beta, prod)

4.8 Domain Migration
  - Migrated from NSDL domains to BH2 (Bharat 2.0) domains
  - Updated all environment configurations during migration
