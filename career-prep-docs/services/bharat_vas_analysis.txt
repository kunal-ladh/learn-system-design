4. KEY ARCHITECTURAL DECISIONS
================================================================================

4.1 Dual-Process Architecture (API + Worker)
  - Separate Docker images for API server and Kafka worker
  - API handles HTTP requests; Worker processes Kafka events
  - Independent scaling and deployment
  - Separate Dockerfiles: Dockerfile (API) and Dockerfile-worker

4.2 Event-Driven Architecture via Kafka
  - Kafka consumers for: account statements, insurance payments,
    policy renewals, cron jobs, transaction events, card status updates,
    job posts, WhatsApp chatbot, settlement handling
  - Zstd compression for Kafka messages (BHAR-502)
  - Delay queue pattern for retry/scheduled processing
  - Audit event publishing with error topic fallback

4.3 Secrets Management Evolution
  - Phase 1: Secrets in config files (hardcoded)
  - Phase 2: AWS Secrets Manager (runtime fetch)
  - Phase 3: Kubernetes secrets (mounted at deploy time)
  - Phase 4: Facets environment variables (platform-managed)
  Decision: Progressively externalized secrets for better security posture

4.4 Multi-Environment Deployment Strategy
  - 4 environments: development, UAT, beta, production
  - Environment-specific config files (config/default.js, staging.js, etc.)
  - Kubernetes deployments per environment
  - Manual promotion gates (UAT → beta → prod)

4.5 Observability Stack
  - Datadog for APM and metrics
  - Custom nc-node-logger with correlation ID support
  - OpenTelemetry annotations (latest addition)
  - AsyncLocalStorage for request context propagation

4.6 Security-First Pipeline
  - SonarQube for code quality and security hotspots
  - Trivy for container image vulnerability scanning
  - OSV Scanner for dependency vulnerabilities
  - Git secret scanning
  - OIDC-based AWS authentication (no static credentials)

4.7 MongoDB Connection Strategy
  - Mongoose with connection pooling
  - Compound indexes for query optimization
  - Projection-based queries to reduce data transfer
  - MongoDB Memory Server for isolated testing

5. BUG FIXES & PRODUCTION ISSUES HANDLED
================================================================================

5.1 Acko Insurance Debit Worker Failure (NMB-375) — Aug 2024
  - Symptom: Insurance debit payments failing silently
  - Root Cause: Kafka payload builder not correctly stringifying payloadVal;
    missing correlation ID in payload
  - Fix: Refactored payload builder, added correlation ID, added granular logging
  - Impact: 7+ PRs over 2 days to diagnose and fix in production
  - Approach: Added logging at each level → identified payload issue → fixed builder

5.2 Kafka Consumer Rebalancing (BHAR-502) — Jul–Aug 2025
  - Symptom: Kafka consumers repeatedly rebalancing, causing message processing delays
  - Root Cause: Consumer configuration and Node.js base image compatibility
  - Fix: Updated KafkaJS version, updated Node base image, refactored Docker image
  - Impact: Stabilized Kafka consumer group across all environments

5.3 Redis Connection Failure (BHAR-568/569) — Dec 2025
  - Symptom: Redis connections failing after Facets migration
  - Root Cause: Cluster mode enabled when Facets Redis is standalone
  - Fix: Turned off redis.clusterMode, updated connection strings, added logging
  - Impact: Restored caching layer functionality

5.4 Account Statement Narration Bugs (BHAR-592) — Dec 2025
  - Symptom: Incorrect fee narrations in customer account statements
  - Root Cause: Narration builder not pulling data from Levy Service
  - Fix: Integrated Levy Service API, updated narration builder for SMS fee,
    subscription fee, and inactivity fee
  - Impact: Correct financial statements for regulatory compliance

5.5 Worker Log Correlation ID Issue (BHAR-200) — Feb 2026
  - Symptom: Kafka worker logs missing correlation IDs
  - Fix: Resolved correlation ID propagation in worker context

5.6 Mongoose Error After AWS SDK Migration (BHAR-663) — Apr 2026
  - Symptom: Build failures and Mongoose errors after AWS SDK v3 migration
  - Fix: Resolved dependency conflicts, fixed build configuration

5.7 Device Endpoint 404 (Sep 2025)

5.8 segfault-handler Build Failure (BHAR-502) — Jul 2025
