## 1. Complexity Analysis — Big O

Big O describes how runtime or memory **scales with input size** in the worst case.

### The Scale

| Complexity | Name | 10 elements | 1000 elements | 10^6 elements |
|---|---|---|---|---|
| O(1) | Constant | 1 | 1 | 1 |
| O(log n) | Logarithmic | 3 | 10 | 20 |
| O(n) | Linear | 10 | 1,000 | 1,000,000 |
| O(n log n) | Log-linear | 30 | 10,000 | 20,000,000 |
| O(n²) | Quadratic | 100 | 1,000,000 | 10^12 (too slow) |
| O(2^n) | Exponential | 1,024 | way too slow | impossible |
| O(n!) | Factorial | 3,628,800 | way too slow | impossible |

**SDE2 target**: prefer O(n log n) or better. O(n²) is usually not acceptable for large inputs.

### Rules

```
Drop constants:       O(2n) = O(n)
Drop lower terms:     O(n² + n) = O(n²)
Add sequential:       O(n) then O(m) = O(n + m)
Multiply nested:      O(n) inside O(n) = O(n²)
Recursive:            T(n) = T(n/2) + O(1) → O(log n) (binary search)
                      T(n) = 2T(n/2) + O(n) → O(n log n) (merge sort)
```

### Space Complexity

Includes: output space, stack space (recursion depth), auxiliary data structures.

```java
// Space O(1) — no extra space grows with input
int sum = 0;
for (int x : arr) sum += x;

// Space O(n) — array/map that grows with input
Map<Integer, Integer> freq = new HashMap<>();
for (int x : arr) freq.merge(x, 1, Integer::sum);

// Space O(h) for tree — h = height of tree
// O(log n) for balanced tree, O(n) for skewed tree
```

### Amortized Analysis

ArrayList `add()` is O(1) amortized even though resizing is O(n), because resizing happens rarely (doubled each time). Over N insertions, total work = O(N).

## 2. Arrays and Strings

Arrays are the foundation. Most interview problems reduce to array manipulation.

### Key Operations

```java
int[] arr = new int[5];          // O(1)
arr[2] = 10;                     // O(1) random access
Arrays.sort(arr);                // O(n log n)
Arrays.binarySearch(arr, 10);    // O(log n)
int[] copy = Arrays.copyOf(arr, arr.length); // O(n)
```

### Core Techniques

**Prefix Sum**: Precompute cumulative sums for O(1) range sum queries.

```java
// Problem: given array, answer Q range sum queries [l, r]
// Naive: O(n) per query = O(Q*n) total
// Prefix sum: O(n) build, O(1) per query

int[] prefix = new int[arr.length + 1];
for (int i = 0; i < arr.length; i++) {
    prefix[i + 1] = prefix[i] + arr[i];
}

// Sum from index l to r (inclusive):
int rangeSum = prefix[r + 1] - prefix[l];
```

**Kadane's Algorithm** — Maximum Subarray Sum:

```java
// Classic: find the contiguous subarray with the largest sum
public int maxSubArray(int[] nums) {
    int maxSoFar = nums[0];
    int maxEndingHere = nums[0];

    for (int i = 1; i < nums.length; i++) {
        // either extend current subarray or start fresh from i
        maxEndingHere = Math.max(nums[i], maxEndingHere + nums[i]);
        maxSoFar = Math.max(maxSoFar, maxEndingHere);
    }
    return maxSoFar;
}
// Time: O(n), Space: O(1)
```

**Dutch National Flag** — 3-way partition:

```java
// Sort array of 0s, 1s, 2s in-place (3 colors)
public void sortColors(int[] nums) {
    int lo = 0, mid = 0, hi = nums.length - 1;
    while (mid <= hi) {
        if (nums[mid] == 0) swap(nums, lo++, mid++);
        else if (nums[mid] == 1) mid++;
        else swap(nums, mid, hi--);
    }
}
// Time: O(n), Space: O(1)
```

**Two Sum pattern**:

```java
// O(n) with HashMap: trade space for time
public int[] twoSum(int[] nums, int target) {
    Map<Integer, Integer> seen = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        int complement = target - nums[i];
        if (seen.containsKey(complement)) {
            return new int[]{seen.get(complement), i};
        }
        seen.put(nums[i], i);
    }
    return new int[]{};
}
```

### String Tricks

## 3. Linked Lists

### Structure

```java
public class ListNode {
    int val;
    ListNode next;
    ListNode(int val) { this.val = val; }
}
```

### Core Techniques

**Fast and Slow Pointers (Floyd's Cycle Detection)**:

```java
// Detect cycle
public boolean hasCycle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;
    }
    return false;
}

// Find middle of linked list
public ListNode findMiddle(ListNode head) {
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    return slow; // slow is at middle
}
```

**Reverse a Linked List** — the most common sub-problem:

```java
public ListNode reverse(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}
```

**Merge Two Sorted Lists**:

```java
public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(0);
    ListNode curr = dummy;
    while (l1 != null && l2 != null) {
        if (l1.val <= l2.val) { curr.next = l1; l1 = l1.next; }
        else { curr.next = l2; l2 = l2.next; }
        curr = curr.next;
    }
    curr.next = l1 != null ? l1 : l2;
    return dummy.next;
}
```

**Find Nth from end** — two-pointer with gap:

```java
public ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(0);
    dummy.next = head;
    ListNode fast = dummy, slow = dummy;
    for (int i = 0; i <= n; i++) fast = fast.next; // advance fast by n+1
    while (fast != null) { fast = fast.next; slow = slow.next; }
    slow.next = slow.next.next; // remove
    return dummy.next;
}
```

**LRU Cache** — HashMap + Doubly Linked List:

```java
public class LRUCache {
    private final int capacity;
    private final Map<Integer, Node> map = new HashMap<>();
    private final Node head, tail; // sentinels

    class Node {
        int key, value;
        Node prev, next;
    }

    public int get(int key) {
        if (!map.containsKey(key)) return -1;
        Node node = map.get(key);
        moveToFront(node);
        return node.value;
    }

    public void put(int key, int value) {
        if (map.containsKey(key)) {
            map.get(key).value = value;
            moveToFront(map.get(key));
        } else {
            if (map.size() == capacity) {
                Node removed = removeLast();
                map.remove(removed.key);
            }
            Node node = new Node(key, value);
            addToFront(node);
            map.put(key, node);
        }
    }
    // addToFront, removeLast, moveToFront methods omitted for brevity
}
// Time: O(1) for both get and put
```

## 4. Stacks and Queues

### Stack (LIFO)

```java
Deque<Integer> stack = new ArrayDeque<>();
stack.push(1);      // O(1)
stack.pop();        // O(1)
stack.peek();       // O(1)
stack.isEmpty();    // O(1)
```

**Monotonic Stack** — the pattern that solves "next greater/smaller element" problems:

```java
// Next Greater Element: for each element, find the next element greater than it
public int[] nextGreaterElement(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];
    Arrays.fill(result, -1);
    Deque<Integer> stack = new ArrayDeque<>(); // stores indices

    for (int i = 0; i < n; i++) {
        // pop elements smaller than current (current is their "next greater")
        while (!stack.isEmpty() && nums[stack.peek()] < nums[i]) {
            result[stack.pop()] = nums[i];
        }
        stack.push(i);
    }
    return result;
}
// Time: O(n) — each element pushed/popped at most once

// Applications: largest rectangle in histogram, trapping rain water,
//               daily temperatures, stock span problem
```

**Valid Parentheses**:

```java
public boolean isValid(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    Map<Character, Character> pairs = Map.of(')', '(', '}', '{', ']', '[');
    for (char c : s.toCharArray()) {
        if ("({[".indexOf(c) >= 0) stack.push(c);
        else if (stack.isEmpty() || stack.pop() != pairs.get(c)) return false;
    }
    return stack.isEmpty();
}
```

### Queue (FIFO)

```java
Queue<Integer> queue = new ArrayDeque<>();
queue.offer(1);     // O(1)
queue.poll();       // O(1)
queue.peek();       // O(1)
```

**Sliding Window Maximum** (Monotonic Deque):

```java
// Find maximum in every sliding window of size k
public int[] maxSlidingWindow(int[] nums, int k) {
    Deque<Integer> dq = new ArrayDeque<>(); // stores indices, maintains decreasing order
    int[] result = new int[nums.length - k + 1];
    int ri = 0;

    for (int i = 0; i < nums.length; i++) {
        // remove indices out of window
        while (!dq.isEmpty() && dq.peekFirst() < i - k + 1) dq.pollFirst();
        // remove smaller elements (they can never be max while current exists)
        while (!dq.isEmpty() && nums[dq.peekLast()] < nums[i]) dq.pollLast();
        dq.offerLast(i);
        if (i >= k - 1) result[ri++] = nums[dq.peekFirst()];
    }
    return result;
}
// Time: O(n), Space: O(k)
```

## 5. Hashing

HashMap and HashSet give O(1) average for get, put, contains.

### Pattern: Frequency Map

```java
// "Group anagrams" — group strings that are anagrams of each other
public List<List<String>> groupAnagrams(String[] strs) {
    Map<String, List<String>> map = new HashMap<>();
    for (String s : strs) {
        char[] chars = s.toCharArray();
        Arrays.sort(chars);
        String key = new String(chars); // sorted string is the key
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }
    return new ArrayList<>(map.values());
}
```

### Pattern: Running Sum with HashMap

```java
// Subarray sum equals k
public int subarraySum(int[] nums, int k) {
    Map<Integer, Integer> prefixCount = new HashMap<>();
    prefixCount.put(0, 1); // empty prefix
    int count = 0, sum = 0;

    for (int num : nums) {
        sum += num;
        // if (sum - k) appeared before, there's a subarray summing to k
        count += prefixCount.getOrDefault(sum - k, 0);
        prefixCount.merge(sum, 1, Integer::sum);
    }
    return count;
}
// Time: O(n), Space: O(n)
```

### HashMap Internals

- Array of buckets (linked lists or red-black trees in Java 8+)
- `hashCode()` → determines bucket; `equals()` → resolves collision
- Load factor: when size/capacity > 0.75, resize (rehash) → O(n) amortized O(1)
- Worst case O(n) if all keys hash to same bucket (pathological input or bad hashCode)
- Java 8+: bins with ≥ 8 entries convert to red-black tree → O(log n) worst case

## 6. Trees

### Binary Tree Traversals

```java
// Inorder (Left → Root → Right) → gives sorted order for BST
void inorder(TreeNode root, List<Integer> result) {
    if (root == null) return;
    inorder(root.left, result);
    result.add(root.val);
    inorder(root.right, result);
}

// Preorder (Root → Left → Right) → clone tree, serialize
void preorder(TreeNode root, List<Integer> result) {
    if (root == null) return;
    result.add(root.val);
    preorder(root.left, result);
    preorder(root.right, result);
}

// Postorder (Left → Right → Root) → delete tree, evaluate expression
void postorder(TreeNode root, List<Integer> result) {
    if (root == null) return;
    postorder(root.left, result);
    postorder(root.right, result);
    result.add(root.val);
}

// Level Order (BFS) — use a Queue
List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;
    Queue<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int size = queue.size(); // snapshot current level size
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            level.add(node.val);
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        result.add(level);
    }
    return result;
}
```

### Key Tree Problems

**Height of tree**:
```java
int height(TreeNode root) {
    if (root == null) return 0;
    return 1 + Math.max(height(root.left), height(root.right));
}
```

**Lowest Common Ancestor (LCA)**:
```java
TreeNode lca(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) return root;
    TreeNode left = lca(root.left, p, q);
    TreeNode right = lca(root.right, p, q);
    if (left != null && right != null) return root; // p and q on opposite sides
    return left != null ? left : right; // both on same side
}
```

**Diameter of Binary Tree**:
```java
int maxDiameter = 0;

int diameter(TreeNode root) {
    dfs(root);
    return maxDiameter;
}

int dfs(TreeNode node) {
    if (node == null) return 0;
    int left = dfs(node.left);
    int right = dfs(node.right);
    maxDiameter = Math.max(maxDiameter, left + right); // path through this node
    return 1 + Math.max(left, right); // height returned to parent
}
```

**Validate BST**:
```java
boolean isValidBST(TreeNode root) {
    return validate(root, Long.MIN_VALUE, Long.MAX_VALUE);
}

boolean validate(TreeNode node, long min, long max) {
    if (node == null) return true;
    if (node.val <= min || node.val >= max) return false;
    return validate(node.left, min, node.val) && validate(node.right, node.val, max);
}
```

**Serialize / Deserialize**:
```java
// Preorder with null markers
public String serialize(TreeNode root) {
    if (root == null) return "null,";
    return root.val + "," + serialize(root.left) + serialize(root.right);
}

public TreeNode deserialize(String data) {
    Queue<String> queue = new ArrayDeque<>(Arrays.asList(data.split(",")));
    return build(queue);
}

private TreeNode build(Queue<String> q) {
    String val = q.poll();
    if ("null".equals(val)) return null;
    TreeNode node = new TreeNode(Integer.parseInt(val));
    node.left = build(q);
    node.right = build(q);
    return node;
}
```

### BST Operations

```
Search:  O(h) — h = height. O(log n) balanced, O(n) skewed.
Insert:  O(h)
Delete:  O(h) — replace with in-order successor
```

**BST Delete — the tricky part**:
```java
TreeNode delete(TreeNode root, int key) {
    if (root == null) return null;
    if (key < root.val) root.left = delete(root.left, key);
    else if (key > root.val) root.right = delete(root.right, key);
    else {
        // found it
        if (root.left == null) return root.right;  // no left child
        if (root.right == null) return root.left;  // no right child
        // two children: replace with in-order successor (smallest in right subtree)
        TreeNode successor = findMin(root.right);
        root.val = successor.val;
        root.right = delete(root.right, successor.val);
    }
    return root;
}
```

### Segment Tree

Answers range queries (sum, min, max) in O(log n) and supports point updates in O(log n).

```java
public class SegmentTree {
    private final int[] tree;
    private final int n;

    public SegmentTree(int[] nums) {
        n = nums.length;
        tree = new int[4 * n];
        build(nums, 0, 0, n - 1);
    }

    private void build(int[] nums, int node, int start, int end) {
        if (start == end) { tree[node] = nums[start]; return; }
        int mid = (start + end) / 2;
        build(nums, 2*node+1, start, mid);
        build(nums, 2*node+2, mid+1, end);
        tree[node] = tree[2*node+1] + tree[2*node+2]; // sum
    }

    public int query(int l, int r) { return query(0, 0, n-1, l, r); }

    private int query(int node, int start, int end, int l, int r) {
        if (r < start || end < l) return 0;  // out of range
        if (l <= start && end <= r) return tree[node]; // fully within range
        int mid = (start + end) / 2;
        return query(2*node+1, start, mid, l, r) + query(2*node+2, mid+1, end, l, r);
    }

    public void update(int idx, int val) { update(0, 0, n-1, idx, val); }

    private void update(int node, int start, int end, int idx, int val) {
        if (start == end) { tree[node] = val; return; }
        int mid = (start + end) / 2;
        if (idx <= mid) update(2*node+1, start, mid, idx, val);
        else update(2*node+2, mid+1, end, idx, val);
        tree[node] = tree[2*node+1] + tree[2*node+2];
    }
}
```

## 7. Heaps / Priority Queues

A heap is a complete binary tree where parent ≥ children (max-heap) or parent ≤ children (min-heap).

```
insert:    O(log n)
peek min:  O(1)
poll min:  O(log n)
heapify:   O(n)   ← build heap from array, NOT O(n log n)
```

```java
PriorityQueue<Integer> minHeap = new PriorityQueue<>();                          // min-heap
PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder()); // max-heap
PriorityQueue<int[]> custom = new PriorityQueue<>(Comparator.comparingInt(a -> a[1])); // custom
```

### Key Patterns

**Top K elements**:
```java
// K largest elements — use min-heap of size K
public int[] topKFrequent(int[] nums, int k) {
    Map<Integer, Integer> freq = new HashMap<>();
    for (int n : nums) freq.merge(n, 1, Integer::sum);

    // min-heap by frequency — evict smallest when size > k
    PriorityQueue<Integer> heap = new PriorityQueue<>(Comparator.comparingInt(freq::get));
    for (int num : freq.keySet()) {
        heap.offer(num);
        if (heap.size() > k) heap.poll(); // remove smallest frequency
    }

    int[] result = new int[k];
    for (int i = k-1; i >= 0; i--) result[i] = heap.poll();
    return result;
}
// Time: O(n log k), Space: O(n)
// Why min-heap for top-k? Keep the k largest; evict small ones.
```

**Kth Largest in a Stream**:
```java
class KthLargest {
    private final PriorityQueue<Integer> heap;
    private final int k;

    public KthLargest(int k, int[] nums) {
        this.k = k;
        heap = new PriorityQueue<>();
        for (int n : nums) add(n);
    }

    public int add(int val) {
        heap.offer(val);
        if (heap.size() > k) heap.poll();
        return heap.peek(); // k-th largest is at top of min-heap
    }
}
```

**Merge K Sorted Lists**:
```java
public ListNode mergeKLists(ListNode[] lists) {
    PriorityQueue<ListNode> heap = new PriorityQueue<>(Comparator.comparingInt(n -> n.val));
    for (ListNode node : lists) if (node != null) heap.offer(node);

    ListNode dummy = new ListNode(0), curr = dummy;
    while (!heap.isEmpty()) {
        ListNode node = heap.poll();
        curr.next = node;
        curr = curr.next;
        if (node.next != null) heap.offer(node.next);
    }
    return dummy.next;
}
// Time: O(N log k) — N total nodes, k lists
```

**Median from Data Stream** (two heaps):
```java
class MedianFinder {
    PriorityQueue<Integer> lower = new PriorityQueue<>(Collections.reverseOrder()); // max-heap for lower half
    PriorityQueue<Integer> upper = new PriorityQueue<>(); // min-heap for upper half

    public void addNum(int num) {
        lower.offer(num);
        upper.offer(lower.poll()); // balance: always push to lower first, then rebalance
        if (lower.size() < upper.size()) lower.offer(upper.poll());
    }

    public double findMedian() {
        return lower.size() > upper.size()
            ? lower.peek()
            : (lower.peek() + upper.peek()) / 2.0;
    }
}
```

## 8. Graphs

Graph = vertices (nodes) + edges. Can be directed/undirected, weighted/unweighted.

### Representations

```java

Map<Integer, List<Integer>> graph = new HashMap<>();
```

### BFS (Breadth-First Search)

```java
// BFS — shortest path in unweighted graph, level-order traversal
public int bfs(int start, int target, Map<Integer, List<Integer>> graph) {
    Queue<Integer> queue = new ArrayDeque<>();
    Set<Integer> visited = new HashSet<>();
    queue.offer(start);
    visited.add(start);
    int distance = 0;

    while (!queue.isEmpty()) {
        int size = queue.size();
        for (int i = 0; i < size; i++) {
            int node = queue.poll();
            if (node == target) return distance;
            for (int neighbor : graph.getOrDefault(node, List.of())) {
                if (!visited.contains(neighbor)) {
                    visited.add(neighbor);
                    queue.offer(neighbor);
                }
            }
        }
        distance++;
    }
    return -1; // unreachable
}
// Time: O(V + E)
```

### DFS (Depth-First Search)

```java
// DFS — connectivity, cycle detection, topological sort, path finding
Set<Integer> visited = new HashSet<>();

void dfs(int node, Map<Integer, List<Integer>> graph) {
    if (visited.contains(node)) return;
    visited.add(node);
    // process node
    for (int neighbor : graph.getOrDefault(node, List.of())) {
        dfs(neighbor, graph);
    }
}
```

### Cycle Detection

```java
// Directed graph: use WHITE/GRAY/BLACK coloring
// GRAY = currently in recursion stack → cycle if we reach a GRAY node
enum Color { WHITE, GRAY, BLACK }

boolean hasCycle(int node, Map<Integer, List<Integer>> graph, Map<Integer, Color> color) {
    color.put(node, Color.GRAY);
    for (int neighbor : graph.getOrDefault(node, List.of())) {
        if (color.get(neighbor) == Color.GRAY) return true; // back edge = cycle
        if (color.get(neighbor) == Color.WHITE && hasCycle(neighbor, graph, color)) return true;
    }
    color.put(node, Color.BLACK);
    return false;
}
```

### Topological Sort

```java
// Kahn's Algorithm (BFS-based) — Course Schedule pattern
public int[] topologicalSort(int n, int[][] prerequisites) {
    int[] indegree = new int[n];
    Map<Integer, List<Integer>> graph = new HashMap<>();

    for (int[] prereq : prerequisites) {
        graph.computeIfAbsent(prereq[1], k -> new ArrayList<>()).add(prereq[0]);
        indegree[prereq[0]]++;
    }

    Queue<Integer> queue = new ArrayDeque<>();
    for (int i = 0; i < n; i++) if (indegree[i] == 0) queue.offer(i);

    int[] order = new int[n];
    int idx = 0;
    while (!queue.isEmpty()) {
        int node = queue.poll();
        order[idx++] = node;
        for (int neighbor : graph.getOrDefault(node, List.of())) {
            if (--indegree[neighbor] == 0) queue.offer(neighbor);
        }
    }
    return idx == n ? order : new int[0]; // if idx < n, cycle exists
}
// Time: O(V + E)
```

### Dijkstra's Algorithm — Shortest Path (Weighted)

```java
public int[] dijkstra(int src, int n, int[][] edges) {
    Map<Integer, List<int[]>> graph = new HashMap<>(); // node → [{neighbor, weight}]
    for (int[] edge : edges) {
        graph.computeIfAbsent(edge[0], k -> new ArrayList<>()).add(new int[]{edge[1], edge[2]});
        graph.computeIfAbsent(edge[1], k -> new ArrayList<>()).add(new int[]{edge[0], edge[2]});
    }

    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[src] = 0;

    PriorityQueue<int[]> pq = new PriorityQueue<>(Comparator.comparingInt(a -> a[1]));
    pq.offer(new int[]{src, 0});

    while (!pq.isEmpty()) {
        int[] curr = pq.poll();
        int node = curr[0], d = curr[1];
        if (d > dist[node]) continue; // outdated entry

        for (int[] edge : graph.getOrDefault(node, List.of())) {
            int neighbor = edge[0], weight = edge[1];
            if (dist[node] + weight < dist[neighbor]) {
                dist[neighbor] = dist[node] + weight;
                pq.offer(new int[]{neighbor, dist[neighbor]});
            }
        }
    }
    return dist;
}
// Time: O((V + E) log V), Space: O(V + E)
// Limitation: doesn't work with negative edge weights (use Bellman-Ford)
```

### Bellman-Ford — Handles Negative Edges

```java
public int[] bellmanFord(int src, int n, int[][] edges) {
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[src] = 0;

    // Relax all edges V-1 times
    for (int i = 0; i < n - 1; i++) {
        for (int[] edge : edges) {
            int u = edge[0], v = edge[1], w = edge[2];
            if (dist[u] != Integer.MAX_VALUE && dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
            }
        }
    }

    // Check for negative-weight cycles
    for (int[] edge : edges) {
        if (dist[edge[0]] + edge[2] < dist[edge[1]]) {
            throw new RuntimeException("Negative cycle detected");
        }
    }
    return dist;
}
// Time: O(V * E)
```

### Union-Find (Disjoint Set Union)

```java
class UnionFind {
    private int[] parent, rank;

    UnionFind(int n) {
        parent = new int[n];
        rank = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;
    }

    int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]); // path compression
        return parent[x];
    }

    boolean union(int x, int y) {
        int px = find(x), py = find(y);
        if (px == py) return false; // already connected — cycle detected!
        if (rank[px] < rank[py]) { int tmp = px; px = py; py = tmp; }
        parent[py] = px;
        if (rank[px] == rank[py]) rank[px]++;
        return true;
    }

    boolean connected(int x, int y) { return find(x) == find(y); }
}
// find: nearly O(1) amortized (inverse Ackermann function)
// Use for: detect cycle in undirected graph, Kruskal's MST, connected components
```

### Minimum Spanning Tree — Kruskal's

```java
public int kruskal(int n, int[][] edges) {
    Arrays.sort(edges, Comparator.comparingInt(e -> e[2])); // sort by weight
    UnionFind uf = new UnionFind(n);
    int totalWeight = 0, edgesUsed = 0;

    for (int[] edge : edges) {
        if (uf.union(edge[0], edge[1])) { // no cycle
            totalWeight += edge[2];
            if (++edgesUsed == n - 1) break; // MST has n-1 edges
        }
    }
    return edgesUsed == n - 1 ? totalWeight : -1; // -1 if graph disconnected
}
// Time: O(E log E)
```

## 9. Tries

A trie (prefix tree) is a tree where each node represents one character. All descendants share a common prefix.

```java
class TrieNode {
    TrieNode[] children = new TrieNode[26];
    boolean isEndOfWord = false;
}

class Trie {
    private final TrieNode root = new TrieNode();

    public void insert(String word) {
        TrieNode curr = root;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (curr.children[idx] == null) curr.children[idx] = new TrieNode();
            curr = curr.children[idx];
        }
        curr.isEndOfWord = true;
    }

    public boolean search(String word) {
        TrieNode node = traverse(word);
        return node != null && node.isEndOfWord;
    }

    public boolean startsWith(String prefix) {
        return traverse(prefix) != null;
    }

    private TrieNode traverse(String s) {
        TrieNode curr = root;
        for (char c : s.toCharArray()) {
            int idx = c - 'a';
            if (curr.children[idx] == null) return null;
            curr = curr.children[idx];
        }
        return curr;
    }
}
// insert/search: O(m) where m = word length
// Space: O(ALPHABET_SIZE * m * N) — N words
```

**Use Trie when**: autocomplete, spell check, prefix-based search, word search in grid.

### Quick Sort — understand the partition

```java
void quickSort(int[] arr, int low, int high) {
    if (low < high) {
        int pivotIndex = partition(arr, low, high);
        quickSort(arr, low, pivotIndex - 1);
        quickSort(arr, pivotIndex + 1, high);
    }
}

int partition(int[] arr, int low, int high) {
    int pivot = arr[high]; // choose last element as pivot
    int i = low - 1;
    for (int j = low; j < high; j++) {
        if (arr[j] <= pivot) {
            i++;
            swap(arr, i, j);
        }
    }
    swap(arr, i + 1, high);
    return i + 1;
}
// Worst case O(n²) when already sorted — randomize pivot to avoid
```

### Merge Sort — understand the merge

```java
void mergeSort(int[] arr, int left, int right) {
    if (left >= right) return;
    int mid = left + (right - left) / 2;
    mergeSort(arr, left, mid);
    mergeSort(arr, mid + 1, right);
    merge(arr, left, mid, right);
}

void merge(int[] arr, int left, int mid, int right) {
    int[] temp = Arrays.copyOfRange(arr, left, right + 1);
    int i = 0, j = mid - left + 1, k = left;
    while (i <= mid - left && j <= right - left) {
        if (temp[i] <= temp[j]) arr[k++] = temp[i++];
        else arr[k++] = temp[j++];
    }
    while (i <= mid - left) arr[k++] = temp[i++];
    while (j <= right - left) arr[k++] = temp[j++];
}
```

### Counting Sort (non-comparison, O(n))

```java
// Works when range of values is known and small
public int[] countingSort(int[] arr, int maxVal) {
    int[] count = new int[maxVal + 1];
    for (int x : arr) count[x]++;
    // prefix sum to get positions
    for (int i = 1; i <= maxVal; i++) count[i] += count[i-1];
    // build output (reverse order for stability)
    int[] output = new int[arr.length];
    for (int i = arr.length - 1; i >= 0; i--) {
        output[--count[arr[i]]] = arr[i];
    }
    return output;
}
```

## 11. Binary Search

Binary search requires the array to be **monotonic** (sorted, or having a property that changes from false to true at some point).

```java
// Classic: find target in sorted array
public int binarySearch(int[] arr, int target) {
    int left = 0, right = arr.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2; // avoid overflow (not (left+right)/2)
        if (arr[mid] == target) return mid;
        else if (arr[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}
```

### The Binary Search Template

Most binary search problems reduce to: **find the first position where condition is true**.

```java
// Template: find leftmost position satisfying condition

while (left < right) { // NOT left <= right
    int mid = left + (right - left) / 2;
    if (condition(mid)) right = mid;   // possible, but look for earlier
    else left = mid + 1;               // not possible, look right
}
// After loop: left == right == answer
```

**Applications**:

## 12. Two Pointers and Sliding Window

### Two Pointers

Used when working with sorted arrays or needing to track two positions.

**Opposite ends** (squeeze inward):
```java
// Two Sum in sorted array
public int[] twoSumSorted(int[] numbers, int target) {
    int left = 0, right = numbers.length - 1;
    while (left < right) {
        int sum = numbers[left] + numbers[right];
        if (sum == target) return new int[]{left+1, right+1};
        else if (sum < target) left++;
        else right--;
    }
    return new int[]{};
}

// Container with most water
public int maxArea(int[] height) {
    int left = 0, right = height.length - 1, max = 0;
    while (left < right) {
        max = Math.max(max, Math.min(height[left], height[right]) * (right - left));
        if (height[left] < height[right]) left++;
        else right--;
    }
    return max;
}
```

**Same direction** (fast and slow, or read and write):

### Sliding Window

A window of variable or fixed size that slides across the array. Avoids recomputing from scratch — O(n) instead of O(n²).

**Fixed window**:
```java
// Maximum sum of subarray of size k
public int maxSumSubarray(int[] nums, int k) {
    int sum = 0;
    for (int i = 0; i < k; i++) sum += nums[i]; // first window
    int maxSum = sum;
    for (int i = k; i < nums.length; i++) {
        sum += nums[i] - nums[i - k]; // slide: add new, remove old
        maxSum = Math.max(maxSum, sum);
    }
    return maxSum;
}
```

**Variable window** (expand right, shrink left when invalid):
```java
// Longest substring without repeating characters
public int lengthOfLongestSubstring(String s) {
    Map<Character, Integer> lastSeen = new HashMap<>();
    int maxLen = 0, left = 0;

    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        if (lastSeen.containsKey(c) && lastSeen.get(c) >= left) {
            left = lastSeen.get(c) + 1; // shrink window to exclude duplicate
        }
        lastSeen.put(c, right);
        maxLen = Math.max(maxLen, right - left + 1);
    }
    return maxLen;
}

// Minimum window substring (contains all chars of t)
public String minWindow(String s, String t) {
    Map<Character, Integer> need = new HashMap<>(), have = new HashMap<>();
    for (char c : t.toCharArray()) need.merge(c, 1, Integer::sum);

    int left = 0, formed = 0, required = need.size();
    int minLen = Integer.MAX_VALUE, minLeft = 0;

    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        have.merge(c, 1, Integer::sum);
        if (need.containsKey(c) && have.get(c).equals(need.get(c))) formed++;

        while (formed == required) { // window is valid — try to shrink
            if (right - left + 1 < minLen) { minLen = right - left + 1; minLeft = left; }
            char lc = s.charAt(left++);
            have.merge(lc, -1, Integer::sum);
            if (need.containsKey(lc) && have.get(lc) < need.get(lc)) formed--;
        }
    }
    return minLen == Integer.MAX_VALUE ? "" : s.substring(minLeft, minLeft + minLen);
}
```

## 13. Recursion and Backtracking

### Recursion Fundamentals

Every recursive function needs:
1. **Base case** — when to stop
2. **Recursive case** — reduce problem size and call self

```java
// Fibonacci — exponential without memoization
int fib(int n) {
    if (n <= 1) return n; // base case
    return fib(n-1) + fib(n-2); // recursive case — O(2^n)
}

// With memoization — O(n)
int[] memo = new int[n+1];
int fibMemo(int n) {
    if (n <= 1) return n;
    if (memo[n] != 0) return memo[n];
    memo[n] = fibMemo(n-1) + fibMemo(n-2);
    return memo[n];
}
```

### Backtracking Template

Backtracking = DFS on a decision tree, pruning branches that can't lead to a solution.

```java
void backtrack(State state, List<Solution> results) {
    if (isSolution(state)) {
        results.add(new Solution(state)); // collect
        return;
    }
    for (Choice choice : getChoices(state)) {
        if (isValid(choice, state)) {
            makeChoice(choice, state);    // choose
            backtrack(state, results);    // explore
            undoChoice(choice, state);    // unchoose (backtrack)
        }
    }
}
```

## 14. Dynamic Programming

DP solves optimization problems with **overlapping subproblems** and **optimal substructure** by storing results of subproblems.

### When to Use DP

Signs it's a DP problem:
- "Find minimum/maximum/count/number of ways"
- Choices at each step affect future choices
- Overlapping subproblems (recursion tree has repeated nodes)
- Optimal substructure: optimal solution to problem contains optimal solutions to subproblems

### DP Approaches

**Top-down (memoization)**: recursive + cache.
```java
Map<String, Integer> memo = new HashMap<>();
int solve(int i, int j, ...) {
    String key = i + "," + j;
    if (memo.containsKey(key)) return memo.get(key);
    // ... recursive calls ...
    memo.put(key, result);
    return result;
}
```

**Bottom-up (tabulation)**: iterative, fill table from base cases.
```java
int[] dp = new int[n+1];
dp[0] = base_case;
for (int i = 1; i <= n; i++) {
    dp[i] = f(dp[i-1], dp[i-2], ...);
}
return dp[n];
```

### Core DP Patterns

**1D DP — Climbing Stairs / Fibonacci**:
```java
// How many ways to climb n stairs taking 1 or 2 steps at a time?
public int climbStairs(int n) {
    if (n <= 2) return n;
    int prev2 = 1, prev1 = 2;
    for (int i = 3; i <= n; i++) {
        int curr = prev1 + prev2;
        prev2 = prev1;
        prev1 = curr;
    }
    return prev1;
}
// Space optimized: O(1) — only need last 2 values
```

**Coin Change** (unbounded knapsack):
```java
// Minimum coins to make amount
public int coinChange(int[] coins, int amount) {
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, amount + 1); // "infinity"
    dp[0] = 0;
    for (int i = 1; i <= amount; i++) {
        for (int coin : coins) {
            if (coin <= i) dp[i] = Math.min(dp[i], dp[i - coin] + 1);
        }
    }
    return dp[amount] > amount ? -1 : dp[amount];
}
// Time: O(amount * coins), Space: O(amount)
```

**0/1 Knapsack**:
```java
// Max value fitting in capacity W
// Each item can be taken once (0 or 1 times)
public int knapsack(int[] weights, int[] values, int W) {
    int n = weights.length;
    int[][] dp = new int[n+1][W+1];
    for (int i = 1; i <= n; i++) {
        for (int w = 0; w <= W; w++) {
            dp[i][w] = dp[i-1][w]; // don't take item i
            if (weights[i-1] <= w) {
                dp[i][w] = Math.max(dp[i][w], dp[i-1][w-weights[i-1]] + values[i-1]); // take item i
            }
        }
    }
    return dp[n][W];
}
// Time: O(n*W), Space: O(n*W) → can optimize to O(W) with 1D array (iterate w backwards)
```

**Longest Common Subsequence (LCS)**:

```java
    for (int j = 0; j < n; j++) dp[0][j] = 1; // first row
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            dp[i][j] = dp[i-1][j] + dp[i][j-1];
        }
    }
    return dp[m-1][n-1];
}
```

**String DP — Palindromic Substrings / Partitioning**:
```java
// Longest palindromic substring — expand around center
public String longestPalindrome(String s) {
    int start = 0, maxLen = 1;
    for (int center = 0; center < s.length(); center++) {
        // odd length
        int len1 = expand(s, center, center);
        // even length
        int len2 = expand(s, center, center+1);
        int len = Math.max(len1, len2);
        if (len > maxLen) {
            maxLen = len;
            start = center - (len - 1) / 2;
        }
    }
    return s.substring(start, start + maxLen);
}

int expand(String s, int l, int r) {
    while (l >= 0 && r < s.length() && s.charAt(l) == s.charAt(r)) { l--; r++; }
    return r - l - 1;
}
```

**Interval DP — Burst Balloons / Matrix Chain Multiplication**:
```java
// Matrix chain multiplication: minimum multiplications to multiply N matrices
// dp[i][j] = min cost to multiply matrices from i to j
public int matrixChainOrder(int[] dims) {
    int n = dims.length - 1;
    int[][] dp = new int[n][n];
    for (int len = 2; len <= n; len++) {
        for (int i = 0; i <= n - len; i++) {
            int j = i + len - 1;
            dp[i][j] = Integer.MAX_VALUE;
            for (int k = i; k < j; k++) {
                int cost = dp[i][k] + dp[k+1][j] + dims[i] * dims[k+1] * dims[j+1];
                dp[i][j] = Math.min(dp[i][j], cost);
            }
        }
    }
    return dp[0][n-1];
}
```

**Classic DP Problems Cheat Sheet**:

| Problem | State | Transition |
|---|---|---|
| Fibonacci | dp[n] = | dp[n-1] + dp[n-2] |
| Climbing Stairs | dp[n] = | dp[n-1] + dp[n-2] |
| Coin Change | dp[amount] = | min(dp[amount-coin]+1) for each coin |
| 0/1 Knapsack | dp[i][w] = | max(dp[i-1][w], dp[i-1][w-wi]+vi) |
| LCS | dp[i][j] = | dp[i-1][j-1]+1 if match, max(dp[i-1][j], dp[i][j-1]) |
| LIS | tails[] | binary search + replace |
| Edit Distance | dp[i][j] = | dp[i-1][j-1] if match, else 1+min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) |
| Unique Paths | dp[i][j] = | dp[i-1][j] + dp[i][j-1] |
| House Robber | dp[i] = | max(dp[i-1], dp[i-2]+nums[i]) |
| Stock Buy/Sell | state machine | track held/notHeld states |

## 15. Greedy Algorithms

Greedy makes the locally optimal choice at each step, hoping to reach a global optimum.

**When greedy works**: when local optimum always leads to global optimum (provable by exchange argument).

### Interval Scheduling

```java
// Activity selection: maximum number of non-overlapping intervals
public int eraseOverlapIntervals(int[][] intervals) {
    Arrays.sort(intervals, Comparator.comparingInt(a -> a[1])); // sort by end time!
    int count = 0, end = Integer.MIN_VALUE;
    for (int[] interval : intervals) {
        if (interval[0] >= end) { // no overlap
            end = interval[1];
        } else {
            count++; // remove this interval
        }
    }
    return count;
}

// Meeting rooms: minimum rooms needed
public int minMeetingRooms(int[][] intervals) {
    Arrays.sort(intervals, Comparator.comparingInt(a -> a[0]));
    PriorityQueue<Integer> ends = new PriorityQueue<>(); // min-heap of end times
    for (int[] interval : intervals) {
        if (!ends.isEmpty() && ends.peek() <= interval[0]) ends.poll(); // reuse room
        ends.offer(interval[1]);
    }
    return ends.size(); // rooms in use at peak
}
```

### Jump Game

```java
// Can you reach the last index?
public boolean canJump(int[] nums) {
    int maxReach = 0;
    for (int i = 0; i < nums.length; i++) {
        if (i > maxReach) return false; // can't reach position i
        maxReach = Math.max(maxReach, i + nums[i]);
    }
    return true;
}

// Minimum jumps to reach end
public int jump(int[] nums) {
    int jumps = 0, currentEnd = 0, farthest = 0;
    for (int i = 0; i < nums.length - 1; i++) {
        farthest = Math.max(farthest, i + nums[i]);
        if (i == currentEnd) { // must jump — reached end of current range
            jumps++;
            currentEnd = farthest;
        }
    }
    return jumps;
}
```

### Task Scheduler

```java
// Minimum time to execute tasks with n cooldown between same tasks
public int leastInterval(char[] tasks, int n) {
    int[] freq = new int[26];
    for (char t : tasks) freq[t-'A']++;
    int maxFreq = Arrays.stream(freq).max().getAsInt();
    int maxCount = (int) Arrays.stream(freq).filter(f -> f == maxFreq).count();
    return Math.max(tasks.length, (maxFreq-1) * (n+1) + maxCount);
}
```

## 16. Bit Manipulation

### Basics

```
& (AND):    1 & 1 = 1, 1 & 0 = 0
| (OR):     1 | 0 = 1, 0 | 0 = 0
^ (XOR):    1 ^ 1 = 0, 1 ^ 0 = 1  (same=0, different=1)
~ (NOT):    ~1 = 0, ~0 = 1
<< (left shift):   x << 1 = x * 2
>> (right shift):  x >> 1 = x / 2  (arithmetic, preserves sign)
>>> (unsigned right shift): fills with 0s
```

### Key Tricks

```java
// Check if bit i is set
boolean isSet = (num & (1 << i)) != 0;

// Set bit i
num = num | (1 << i);

// Clear bit i
num = num & ~(1 << i);

// Toggle bit i
num = num ^ (1 << i);

// Check if power of 2: n & (n-1) == 0 (and n > 0)
boolean isPowerOf2 = n > 0 && (n & (n-1)) == 0;

// Count set bits (Brian Kernighan's algorithm)
int countBits(int n) {
    int count = 0;
    while (n != 0) { n &= (n-1); count++; } // n & (n-1) clears lowest set bit
    return count;
}

// XOR cancellation: a ^ a = 0, a ^ 0 = a
// Find the single non-duplicate element in array of pairs
int singleNumber(int[] nums) {
    int result = 0;
    for (int n : nums) result ^= n; // all pairs cancel, single remains
    return result;
}

// Get lowest set bit
int lowest = n & (-n);  // -n = ~n + 1

// Clear lowest set bit
n = n & (n-1);

// Swap without temp variable
a ^= b; b ^= a; a ^= b;
```

### Bitmask DP

```java
// Traveling Salesman Problem (TSP) — visit all N cities, minimum cost
// State: dp[mask][city] = min cost to reach 'city' having visited cities in 'mask'
int tsp(int[][] dist, int n) {
    int FULL = (1 << n) - 1; // all cities visited
    int[][] dp = new int[1 << n][n];
    for (int[] row : dp) Arrays.fill(row, Integer.MAX_VALUE / 2);
    dp[1][0] = 0; // start at city 0, mask = 0001

    for (int mask = 1; mask < (1 << n); mask++) {
        for (int city = 0; city < n; city++) {
            if ((mask & (1 << city)) == 0) continue;
            for (int next = 0; next < n; next++) {
                if ((mask & (1 << next)) != 0) continue;
                int newMask = mask | (1 << next);
                dp[newMask][next] = Math.min(dp[newMask][next], dp[mask][city] + dist[city][next]);
            }
        }
    }
    int ans = Integer.MAX_VALUE;
    for (int city = 1; city < n; city++) {
        ans = Math.min(ans, dp[FULL][city] + dist[city][0]);
    }
    return ans;
}
// Time: O(2^n * n²), Space: O(2^n * n) — feasible for n ≤ 20
```

## 17. Math and Number Theory

### GCD and LCM

```java
// Euclidean algorithm: GCD(a, b) = GCD(b, a % b)
int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);
}

// LCM: a * b / gcd(a, b)
long lcm(long a, long b) {
    return a / gcd(a, b) * b; // divide first to avoid overflow
}
```

### Sieve of Eratosthenes — Find all primes up to N

```java
boolean[] sieve(int n) {
    boolean[] isPrime = new boolean[n+1];
    Arrays.fill(isPrime, true);
    isPrime[0] = isPrime[1] = false;
    for (int i = 2; i * i <= n; i++) {
        if (isPrime[i]) {
            for (int j = i*i; j <= n; j += i) {
                isPrime[j] = false;
            }
        }
    }
    return isPrime;
}
// Time: O(n log log n)
```

### Modular Arithmetic

```java
// (a + b) % mod = (a%mod + b%mod) % mod
// (a * b) % mod = ((a%mod) * (b%mod)) % mod
// (a - b) % mod = (a%mod - b%mod + mod) % mod  ← add mod to handle negative

// Fast modular exponentiation: a^b mod m
long power(long base, long exp, long mod) {
    long result = 1;
    base %= mod;
    while (exp > 0) {
        if ((exp & 1) == 1) result = result * base % mod;
        base = base * base % mod;
        exp >>= 1;
    }
    return result;
}
// Time: O(log exp)
```

### Combinations (nCr)

```java
// nCr = n! / (r! * (n-r)!)
// Pascal's triangle approach — avoids large factorial computation
long nCr(int n, int r) {
    if (r > n - r) r = n - r; // optimization: nCr = nC(n-r)
    long result = 1;
    for (int i = 0; i < r; i++) {
        result = result * (n - i) / (i + 1);
    }
    return result;
}
```

## 18. Problem Pattern Recognition Guide

When you see a problem, map it to a pattern before writing code.

| Signal in problem | Pattern to apply |
|---|---|
| "Find max/min in subarrays" | Sliding window or monotonic deque |
| "Subarray sum equals k" | Prefix sum + HashMap |
| "Sorted array, find pair" | Two pointers |
| "Shortest path, unweighted" | BFS |
| "Shortest path, weighted, no negative" | Dijkstra |
| "Shortest path, with negative edges" | Bellman-Ford |
| "Detect cycle in graph" | DFS (coloring) or Union-Find |
| "Topological order / prerequisite" | Topological sort (Kahn's) |
| "Connected components" | Union-Find or DFS/BFS |
| "Min spanning tree" | Kruskal (Union-Find) or Prim |
| "Next greater/smaller element" | Monotonic stack |
| "K largest/smallest elements" | Heap (PriorityQueue) |
| "Median from stream" | Two heaps |
| "Prefix search, autocomplete" | Trie |
| "Optimization with choices, overlapping subproblems" | Dynamic Programming |
| "All combinations/permutations/subsets" | Backtracking |
| "Sorted structure, insert/delete/findMin" | TreeMap / TreeSet |
| "Find first/last position of condition" | Binary search on answer |
| "Scheduling, intervals, meetings" | Greedy (sort by end time) |
| "XOR, unique element, power of 2" | Bit manipulation |
| "String matching/anagram" | HashMap frequency count |
| "Range queries with updates" | Segment tree |

### Complexity Goals by Input Size

```
n ≤ 10:         O(n!) or O(2^n) — backtracking, brute force
n ≤ 20:         O(2^n * n) — bitmask DP
n ≤ 100:        O(n³) — Floyd-Warshall, interval DP
n ≤ 1,000:      O(n²) — 2D DP, all-pairs BFS
n ≤ 10,000:     O(n² ) — bubble sort if forced, n² DP
n ≤ 100,000:    O(n log n) — sorting, segment tree, heap
n ≤ 1,000,000:  O(n) — linear scan, two pointers, sliding window
n ≤ 10^9:       O(log n) — binary search, fast exponentiation
```

### Problem-Solving Steps (in interview)

1. **Understand**: restate the problem, confirm examples
2. **Clarify constraints**: n ≤ 10^5? integers or strings? duplicates? negatives?
3. **Brute force first**: say it out loud, give its complexity
4. **Optimize**: what's the bottleneck? What pattern applies?
5. **Code**: write clean code top-down (main function first, helpers after)
6. **Test**: trace through examples, edge cases (empty, single element, all same, all max)

### Edge Cases to Always Check

```
Empty input: arr.length == 0, s.isEmpty()
Single element: arr.length == 1
All same elements: [1,1,1,1]
Already sorted / reverse sorted
Integer overflow: use long when products can exceed 2^31
Negative numbers: sum can be negative, "minimum" might be negative
Cycles in graphs: need visited set
Tree vs BST: generic tree ≠ BST property
Off-by-one: 0-indexed vs 1-indexed, inclusive vs exclusive
```
