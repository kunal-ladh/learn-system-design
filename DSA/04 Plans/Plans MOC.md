# Plans MOC

**Map:** [[DSA Dashboard]] · [[Topics MOC]] · [[NeetCode 150 MOC]]



- [[8-Week DSA Plan]] — The eight-week order through this vault: which topic notes to read each week, which NeetCode problems to solve (all 150, grouped by week and category), the daily routine for a working engineer, the rules that stop the plan from quietly dying, and how the dashboard properties track it.
- [[Spaced Repetition Protocol]] — How revisions are scheduled in this vault: the +3/+7/+21-day ladder, what counts as a pass, exactly which properties to set after each attempt, how the Revision Queue base reads them, and the Sunday review ritual.

- [[Pattern Recognition Table]] — Forty rows from the words in a problem statement to the pattern they signal, the topic note that teaches it and the two problems to try first — the table to scan in the first five minutes of a round when nothing comes to mind.
